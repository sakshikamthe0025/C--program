# Jay Ganesh - C Program

## Description
This is a simple C program that prints `Jay Ganesh...` to the console.

## Source File
- `program1.c` — contains the C source code.

## Requirements
- A C compiler, such as GCC.
- A terminal or command prompt.

## How to Compile and Run

### Using GCC
1. Open a terminal or command prompt in the folder containing `program1.c`.
2. Compile the program:

   ```bash
   gcc program1.c -o program1
   ```

3. Run the program:

   **Windows:**
   ```bash
   program1.exe
   ```

   **Linux/macOS:**
   ```bash
   ./program1
   ```

## Expected Output

```text
Jay Ganesh...
```

## Concepts Used
- `stdio.h` for standard input/output.
- `main()` as the program's entry point.
- `printf()` to display text.
- `return 0` to indicate successful program completion.
